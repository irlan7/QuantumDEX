# Contributing to QuantumDEX

Thank you for your interest in contributing to QuantumDEX.

## What's Open for Contribution

This public repository contains documentation, SDK examples, public API references, and interface definitions. The core trading engine, matching engine, risk engine, and AI models remain proprietary and are not open for external contribution.

You can contribute to:
- Documentation improvements
- SDK examples (new language bindings, usage examples)
- Bug reports for the public-facing API
- Architecture diagram clarity/accuracy suggestions

## How to Contribute

1. Fork this repository
2. Create a feature branch (`git checkout -b docs/improve-sdk-example`)
3. Make your changes
4. Commit with a clear message describing the change
5. Open a Pull Request describing what you changed and why

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](./CODE_OF_CONDUCT.md).

## Questions

For questions about contributing, reach out via the contact details on [dex.quantumpaychain.org](https://dex.quantumpaychain.org).
