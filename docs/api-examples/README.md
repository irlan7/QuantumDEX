# API Examples

Live examples using the QuantumDEX public REST API and WebSocket feed.

Base URL: `https://api.quantumpaychain.org`

## Contents

- [`rest-market-data.md`](./rest-market-data.md) — fetching market stats, orderbook, and candle history
- [`rest-chains.md`](./rest-chains.md) — querying supported chains and cross-chain balances
- [`websocket-orderbook.md`](./websocket-orderbook.md) — subscribing to live trade/orderbook updates

All examples use `curl` for portability. Any HTTP client works identically.
